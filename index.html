每个功能是干什么的（点开）
  1. 拖文件进来：DeepSeek 网页版「导出全部对话」会给你一个 zip。直接拖进上面的虚线框；也可以只拖其中一个会话的 json。图片多不影响，只读文字。
  2. 列表：每一行是一个对话，显示标题、多少条、最后聊天时间、第一句话。认不出来就在搜索框打关键词。
  3. 勾选：可以选一个，也可以选很多个，导出时会按顺序拼起来。
  4. 带最近 N 条：只把最后的 N 条原样带过去。填 0 就是全部带。对话很长时建议填 20–40，不然会超出模型能记住的长度。
  5. 前面压缩成摘要：超过 N 条之前的部分，自动压成"前情提要 + 片段节选"，比全文省很多 token。
  6. 分段格式 / 自然口语：分段格式用 ===== 最近的对话 ===== 这类标记把内容分开，模型更容易分清边界；自然口语就是把话连起来说，读着更顺。两种内容一样，只是排版不同。
  7. 自动判断 / 角色扮演 / 普通聊天：角色扮演会要求它保持人设、用角色语气说话；普通聊天只是带着上下文继续聊，不会硬加演戏的腔调。不确定就选自动。
  8. 人设卡：从对话开头读出的人设，可以自己改。贴进客户端的系统提示词后，每次新建对话都自动带着，不用重复粘。
  9. 续接包：把「人设 + 前面的摘要 + 最近的对话」拼成一段话。粘给新客户端发出去，它读完就接上了。
  10. 存成 Markdown：把对话存成 .md 文件，用来存档、看，或者当资料库丢给客户端。
  11. 隐私：所有解析都在你的浏览器里完成，不上传任何内容，断网也能用。
