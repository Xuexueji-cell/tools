对话搬运工

DeepSeek 导出专用

把 DeepSeek 导出的对话包拖进来，就能看清每个对话是什么，挑好再搬去 Chatbox / Kelivo 接着聊。
全部在你自己的浏览器里跑，不上传，断网也能用。

把 zip 或 json 拖到这里，或点击选择
整个导出包也行，只丢一个对话也行，支持多选
续接包带最近
怎么用（点开）
  • 拖进来：DeepSeek 网页版导出会生成一个 zip，直接拖进来。图片多也没关系，只解析对话。
  • 挑对话：列表里写了标题、条数、时间和第一句话。认不出来就搜关键词。
  • 导出：「拿去接着聊」会生成一段话，粘给新的客户端就能续上，里面带了人设和最近的对话。
  • 人设卡：想让它一直记得这个角色，把卡片贴进客户端的系统提示词，以后新对话自动带上。
  • 普通聊天：如果本来就是在跟 DeepSeek 本体聊天，类型选「普通聊天」，不会加角色扮演的腔调。
  • 隐私：全部在本地浏览器里完成，不上传，断网也能用。
